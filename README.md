# make-knowledge-cards

## 1. 解决什么问题

阅读文章时，重要概念容易被重复表述和细节淹没；直接摘要又不方便逐点复习。这个 Codex Skill 将用户提供的文章提炼成一组可复习的知识卡片，同时尽量忠于原文。它是给支持 Agent Skills 的 Codex 使用的指令包，不是独立运行的命令行程序。

## 2. 主要功能

- 输入用户粘贴的文章，或本地 `.md` / `.txt` 文件。
- 通常生成 5～8 张卡片；只在原文支持足够多不同知识点时达到该数量，信息不足时会少生成并说明原因。
- 每张卡片包含标题、核心知识、简明解释，以及原文中的例子或能从原文回答的自测题。
- 合并重复内容；一张卡片聚焦一个知识点，不补入原文没有的事实、论据或例子。
- 仅生成文本卡片；不抓取网页、不处理 PDF、不生成 Anki 卡组或图形界面。

## 3. 安装方法

获取项目文件后，可将 Skill 文件夹复制到 Codex 的仓库级或个人级发现目录。以下命令在项目根目录执行，二选一：

**仅用于当前仓库：**

```sh
mkdir -p .agents/skills
cp -R skills/make-knowledge-cards .agents/skills/
```

**用于个人 Codex 环境：**

```sh
mkdir -p "$HOME/.agents/skills"
cp -R skills/make-knowledge-cards "$HOME/.agents/skills/"
```

本 Skill 不需要额外依赖或构建步骤。Codex 会发现这些目录中的 Skill；如果安装后没有显示，可重启 Codex。目录位置和发现方式见 [Codex Skills 文档](https://learn.chatgpt.com/docs/build-skills)。

## 4. 使用方法

在 Codex 对话中输入 `$make-knowledge-cards`，再粘贴文章；或者附上本地 `.md` / `.txt` 文件并说明要将其整理成知识卡片。输出为 Markdown 文本。

## 5. 输入输出示例

**输入：**

> 团队会前先写清本次会议目标和议程，并提前告诉参会者需要准备什么。会议中记录决定和待办即可，不必逐字记录发言。若讨论偏离议程，主持人把问题写入待议清单，先回到当前议程。每条待办写明一个负责人和完成期限。会后尽快分享记录并请参会者指出错误；下次会议开始时检查未完成的待办。

**输出：**

### 卡片 1｜会前明确目标、议程和准备事项
- **核心知识：** 会前写清会议目标与议程，并告诉参会者需要准备什么。
- **简明解释：** 参会者可以据此了解会议安排和会前准备要求。
- **自测：** 会前应明确并告知哪些事项？**答：**会议目标、议程，以及参会者需要准备的内容。

### 卡片 2｜会议记录聚焦决定和待办
- **核心知识：** 记录会议决定和待办，不必逐字记录发言。
- **简明解释：** 记录保留文章指定的结果与行动信息，而非完整对话。
- **自测：** 按原文，会议中需要记录什么？**答：**决定和待办。

### 卡片 3｜把偏题内容暂存到待议清单
- **核心知识：** 讨论偏离议程时，将问题写入待议清单，再回到当前议程。
- **简明解释：** 这样处理偏题问题的步骤来自原文，不需要替它补充额外规则。
- **自测：** 讨论偏离议程时，主持人应如何处理？**答：**记入待议清单，然后回到当前议程。

### 卡片 4｜每条待办指定负责人和期限
- **核心知识：** 每条待办都要写明负责人和完成期限。
- **简明解释：** 这两项信息共同说明由谁负责、何时完成。
- **自测：** 原文要求每条待办标明哪两项信息？**答：**负责人和完成期限。

### 卡片 5｜会后分享记录并征求纠错
- **核心知识：** 会后尽快分享记录，并请参会者指出错误。
- **简明解释：** 记录分享后，参会者可以根据原文要求反馈错误。
- **自测：** 分享会议记录后，应请参会者做什么？**答：**指出记录中的错误。

### 卡片 6｜下次会议检查未完成待办
- **核心知识：** 在下次会议开始时检查尚未完成的待办。
- **简明解释：** 检查时点是原文明确给出的“下次会议开始时”。
- **自测：** 何时检查未完成的待办？**答：**下次会议开始时。
